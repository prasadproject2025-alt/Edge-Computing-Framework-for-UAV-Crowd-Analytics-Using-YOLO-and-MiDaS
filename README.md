# Edge Computing Framework for UAV Crowd Analytics Using YOLO and MiDaS

This project presents an **Edge Computing Framework for UAV-based Crowd Analytics** by integrating real-time object detection using **YOLO** with monocular depth estimation using **Intel's MiDaS**.

The system processes aerial video captured by UAVs to detect people and other objects while estimating their relative depth from the camera. By combining object detection with depth information, the framework provides better spatial awareness than conventional 2D object detection.

The proposed approach is suitable for **crowd monitoring, UAV surveillance, smart cities, public safety, disaster management, and edge-AI applications**.

## Features

* Real-time object and person detection using YOLO.
* Monocular depth estimation using Intel's MiDaS.
* Designed for UAV-based crowd monitoring and analytics.
* Combines 2D object detection with relative depth information.
* Generates real-time depth maps from UAV video frames.
* Estimates the relative spatial positions of detected objects.
* Supports confidence-threshold-based detection filtering.
* Provides bounding boxes and class labels for detected objects.
* Supports object tracking for analyzing movement across video frames.
* Provides an intuitive Bird's Eye View / top-down representation of detected objects.
* Designed with edge computing scenarios in mind to reduce dependence on cloud-based processing.
* Can be extended for real-time UAV video streams and edge devices.

## How It Works

The framework combines two major computer vision components:

### YOLO Object Detection

YOLO processes each UAV video frame and detects objects such as people and vehicles. For every detected object, information such as the bounding box, object class, and confidence score can be obtained.

### MiDaS Depth Estimation

MiDaS estimates a relative depth map from a single RGB frame. Unlike stereo-camera-based approaches, MiDaS can estimate scene depth using only one camera.

### YOLO + MiDaS Integration

The YOLO bounding boxes are combined with the depth information generated by MiDaS. The estimated depth corresponding to each detected object can then be used to understand its relative position in the scene.

This transforms conventional 2D object detection into a more spatially aware crowd analytics system.

## Edge Computing

Instead of transmitting every UAV video frame to a remote cloud server, the computer vision pipeline can be deployed closer to the data source using edge computing.

This approach can provide:

* Reduced communication latency
* Faster decision-making
* Lower network bandwidth requirements
* Improved real-time processing
* Reduced dependency on continuous cloud connectivity

These characteristics are particularly useful for UAV surveillance and emergency-response applications.
